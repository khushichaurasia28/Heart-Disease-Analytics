What changed in preprocessing

  1. Standardized the source fields. Column names are normalized and values are converted to numeric form; question marks and unparseable entries are treated as missing.
  2. Checked duplicates. Exact duplicate rows are removed before analysis. This file contains {{ cleaning.duplicate_rows }} duplicate rows.
  3. Handled missing measurements. Missing ca and thal values are filled with their respective column medians. No records are removed for these missing measurements.
  4. Prepared the analysis outcome. Original target 0 is labeled “No disease”; original values 1–4 are grouped as “Disease present”. This is a descriptive grouping, not a model output.
  5. Added readable categories. Sex and age-group labels are derived from the source values to support charts and filtering.
