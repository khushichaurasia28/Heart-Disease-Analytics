Heart Disease Analytics

A descriptive data analytics project using the Cleveland subset of the UCI Heart Disease dataset. The project focuses on data preparation, exploratory analysis and presenting meaningful insights through an interactive dashboard.

OBJECTIVE

Project scope

Prepare the cardiovascular dataset, study how age, sex, cholesterol and resting blood pressure vary across the recorded outcome groups, and present those observations in a usable analytics interface.

This project does not train a machine-learning model and does not produce individual diagnoses or risk scores.

METHODOLOGY

How the analysis was done

  1. Load and inspect the original CSV without replacing it.
  2. Normalize fields, remove exact duplicates and impute missing ca/thal values using column medians.
  3. Group the original outcome as 0 versus 1–4 for descriptive comparisons.
  4. Explore distributions and summary statistics with Pandas.
  5. Present findings in Flask and prepare a processed CSV for Tableau.
